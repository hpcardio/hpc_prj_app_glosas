# Pluggy — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Integrar o backend do ProntoGlosa à Pluggy para saldos e extratos com webhook HTTPS.

**Architecture:** API e worker próprios, PostgreSQL com schema isolado, nginx já existente. Webhook persistente e processamento assíncrono; consulta de extratos sempre no armazenamento local.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2, psycopg, PyJWT, httpx, PostgreSQL, Docker/nginx.

**Spec:** `docs/superpowers/spec.md`

## Global Constraints
- Somente contas BANK, saldos e extratos; nenhuma operação bancária de pagamento.
- Preservar API principal, alterações locais e histórico financeiro existente.
- Piloto sandbox; credenciais somente no servidor.
- JWT existente, usuário ativo TI e separação por titular/usuário.

## Review Focus
- Webhook duplicado e fora de ordem não duplica movimentos.
- Falha em página intermediária preserva snapshot e saldo anteriores.
- Nenhum usuário acessa titular/conta de outro usuário.
- Conexão ou conta inesperada nunca atravessa o vínculo de titular.
- Revogação, indisponibilidade e produtos parciais não parecem saldo atualizado.
