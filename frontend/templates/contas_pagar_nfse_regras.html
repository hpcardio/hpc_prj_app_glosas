Para qual setor vai cada NFS-e recebida

O setor de cada fornecedor é definido pelo histórico de entradas de serviço no MV (últimos 24 meses, por empresa): quando um setor concentra 80% ou mais das entradas, as notas vão direto para ele. Os demais casos ficam aqui para classificar. Classificações manuais nunca são substituídas pelo recálculo.
